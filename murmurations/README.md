# Murmurations

Murmurations is the training and evaluation package for a compact,
Starlings-native policy model.

The v0 model is a ~500M decoder-only transformer with one shared backbone and
three output heads:

```text
                         shared transformer
                    /          |           \
                   /           |            \
          language head   operation head   argument head
          code / prose     protocol op      kind / span /
                                          operator /
                                          parents / confidence
```

The operation vocabulary is:

`OBSERVE`, `QUERY`, `CLAIM`, `EVIDENCE`, `PROPOSE`, `ACCEPT`,
`REJECT`, `CHALLENGE`, `RETRACT`, `DELEGATE`, and `EXECUTE`
(plus `NOOP` for ordinary language/code windows).

## Operator Retrieval

The model does not memorize a fixed tool catalog. Training environments expose
operator descriptors and **Operator Retrieval (OR)** returns a bounded relevant
set. The argument head points at a retrieved operator already present in
context. OR only retrieves capabilities; it does not execute tools or declare a
workflow.

The initial training substrate is intentionally pragmatic:

- repository/source search -> Python adapter
- Python AST inspection -> Python adapter
- local docs/package search -> Python adapter
- compiler/build/test verification -> argv subprocess
- WASM -> optional future operator implementation

## Training data

Two streams can be mixed by the same trainer:

1. ordinary code/document continuation windows dynamically materialized from a
   permissive, pinned repository catalog;
2. verifier-grounded protocol episodes generated by mutating a known-good
   repository, proving the verifier catches the mutation, recording OR/tool
   interactions as a Merkle-DAG, repairing the mutation, and verifying again.

Bootstrap repair traces are labeled `oracle-bootstrap-v1`; they are supervised
demonstrations built from known mutation truth, not claimed emergent reasoning.

## Layout

- `training/` — tokenizer, model, OR, operator adapters, dynamic environments,
  trajectory/code materialization, losses, and Accelerate training.
- `models/` — versioned architecture manifests/configuration.
- `utils/` — protocol frames, canonical BLAKE3 identity, DAGs, and population
  context.
- `benchmarking/` — model-head, OR, replay/provenance, and executable coding
  evaluation.

The local-k=7 parameter-agent idea remains a later ablation. First train and
measure the fixed 500M protocol-native baseline.
