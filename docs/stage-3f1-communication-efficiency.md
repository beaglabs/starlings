# Stage 3F.1 — Communication Efficiency Under Budget

Stage 3F.1 moves the controlled-emergence question from simple convergence to
communication efficiency:

> Can autonomous Starlings populations preserve collective success when
> communication is explicitly scarce, and does CFG control change the amount
> or usefulness of information exchanged?

Stage 3F.0 established same-state trajectory diversity and 100% collective
success in both A/B arms. It also showed higher duplicate fact transmission in
the constrained arm. Stage 3F.1 makes redundant communication materially
costly.

## Environment

Five workers remain on a static ring:

~~~text
W1 — W2 — W3 — W4 — W5
|                   |
└───────────────────┘
~~~

The world contains ten facts, A through J. For environment seed 0:

~~~text
W1: A,B,C,D
W2: C,D,E,F
W3: E,F,G,H
W4: G,H,I,J
W5: I,J,A,B
~~~

Each worker starts with four facts and every fact exists at exactly two
workers. Environment seeds rotate this assignment while preserving the overlap
structure.

Worker 1 is the collector. Success means Worker 1 learns A through J.

## Per-worker communication budget

Default:

~~~text
16 communication units per worker
80 maximum units across five workers
~~~

Budgets are local to avoid cross-worker ordering effects in synchronous rounds.

CLAIM cost:

~~~text
CLAIM E,F

2 facts × 2 ring neighbors = 4 communication units
~~~

In general, CLAIM costs 2 times the number of distinct claimed facts.

QUERY EVIDENCE cost:

~~~text
2 query units
+ 1 evidence unit per responding neighbor
= 2 to 4 communication units
~~~

If an otherwise valid action exceeds the sender's remaining budget, the action
is rejected without changing state or budget.

Budget rejection is measured separately from syntax errors and semantic
violations.

## Why the default budget is 16

The deterministic core includes a selective two-round solution:

~~~text
Round 1
W2 CLAIM E,F
W3 CLAIM G,H
W5 CLAIM I,J

Round 2
W2 CLAIM G,H
~~~

That path solves the collector using only 16 communication units total.

By contrast, all five workers broadcasting all four initial facts costs 40
units in the first round alone. Repeating broad claims after knowledge expands
causes deterministic per-worker budget rejections.

The task therefore leaves room for selective coordination while penalizing
careless retransmission.

## Autonomous actions

The model still chooses its own action:

~~~text
CLAIM <facts>
QUERY EVIDENCE <fact>
~~~

The prompt includes identity, neighbors, private facts, current knowledge,
current round, remaining budget, initial budget, and the global objective. It
does not prescribe a trajectory.

## Paired A/B design

Each experimental key is:

~~~text
(environment_seed, sampling_seed)
~~~

Both typed/unconstrained and CFG-constrained arms use the same model, initial
world, sampling seed, deterministic per-turn model seeds, sampler settings,
reasoning controls, token budget, worker budget, topology, and maximum rounds.

Only the constrained arm receives grammars/stage3f1.gbnf.

The grammar controls syntax only. A grammar-valid action can still be
semantically invalid, exceed budget, be redundant, or fail the global task.

## Raw record and deterministic replay

Each TSV row records:

~~~text
environment_seed
sampling_seed
mode
round
worker
knowledge_before
budget_before
worker_budget
generation_seed
completion_tokens
latency_us
completion
~~~

The Zig summary independently reconstructs knowledge, remaining budgets,
generation seeds, synchronous state transitions, communication cost, and final
collector state. Mismatched knowledge or budget makes a run unreplayable.

## Metrics

Primary:

~~~text
collective success under budget
~~~

Control metrics:

- protocol validity
- invalid actions
- semantic violations
- budget rejections
- backend errors

Efficiency metrics:

- communication units
- logical network messages
- useful fact deliveries
- duplicate fact transmissions
- useful facts per communication unit
- rounds
- completion tokens
- generated bytes
- latency

The summary also reports paired A/B rows and same-environment successful
trajectory diversity.

## Default replication

~~~text
5 environments
× 4 sampling seeds
× 2 modes
= 40 population runs

40 populations
× 8 rounds
× 5 workers
= up to 1,600 model generations
~~~

Runs stop early when Worker 1 learns all ten facts.

## Stage 3F.1 gate

A favorable formal-control signal would preserve collective success and
trajectory diversity while improving protocol validity without materially
increasing communication units, ideally with better useful-facts-per-unit.

A result where CFG achieves perfect syntax but lower success or materially
higher communication cost is equally important evidence: it would show that
formal constraint is distorting useful emergent coordination.

Stage 3F.1 alone does not promote CFG. Later experiments still need error
correction, delegation/specialization, failure resilience, and topology stress.
